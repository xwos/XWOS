## MODIFIED Requirements

### Requirement: %g 移除尾随零

默认情况下（无 `#` 标志），`%g` SHALL 移除小数部分的尾随零；若小数部分全部为零，SHALL 同时移除小数点。带 `#` 标志时 SHALL 保留尾随零与小数点；当精度为 0（有效数字 P=1，小数位数为 0）且带 `#` 标志时，SHALL 输出小数点但不输出任何数字。

#### Scenario: 移除尾随零

- **WHEN** 以 `%g` 格式化 1.500
- **THEN** 输出 `1.5`

#### Scenario: 移除空小数点

- **WHEN** 以 `%.2g` 格式化 1500.0
- **THEN** 输出 `1.5e+03`

#### Scenario: # 标志保留尾随零

- **WHEN** 以 `%#.2g` 格式化 1500.0
- **THEN** 输出 `1.50e+03`（带 # 时保留尾随零；科学计数法小数位为 P−1=1）

#### Scenario: 定点风格下 # 标志保留小数部分

- **WHEN** 以 `%#.3g` 格式化 1.5
- **THEN** 输出 `1.50`（# 保留尾随零）

#### Scenario: # 标志与精度 0 输出空小数部分

- **WHEN** 以 `%#.0g` 格式化 3.0（P=1，定点风格，小数位数 0）
- **THEN** 输出 `3.`（小数点出现，小数点后无数字）

#### Scenario: # 标志与精度 0 的科学计数法

- **WHEN** 以 `%#.0g` 格式化 1234567.0（X=6 ≥ P=1，科学计数法，小数位数 P−1=0）
- **THEN** 输出 `1.e+06`（小数点出现，小数点后无数字）

#### Scenario: 共享路径修复 %f 与 %e

- **WHEN** 以 `%#.0f` 格式化 3.0，或以 `%#.0e` 格式化 3.0
- **THEN** 输出 `3.` 与 `3.e+00`（`%f`/`%e` 共享 `xwvsnpf_put_float_decimal()`，同样不输出冗余 `0`）

### Requirement: %g 特殊值与符号处理

`%g` SHALL 对 NaN 输出 `nan`、对无穷大输出 `inf`/`-inf`（大小写固定为小写，不受 `%G` 影响）。nan/inf 的输出 SHALL 应用符号标志：负 NaN/负无穷（`signbit` 为真）输出 `-` 前缀；`+` 标志输出 `+` 前缀；空格标志输出空格前缀。负数（含 −0.0）的负号 SHALL 正常输出。

#### Scenario: 负零输出

- **WHEN** 以 `%.3g` 格式化 −0.0
- **THEN** 输出 `-0`

#### Scenario: 大整数部分不溢出缓冲区

- **WHEN** 以 `%g` 格式化 1.0e20
- **THEN** 输出 `1e+20`，不产生缓冲区溢出

#### Scenario: 负 NaN 输出负号

- **WHEN** 以 `%g` 格式化 −NaN
- **THEN** 输出 `-nan`（负号跟随 NaN 的符号位）

#### Scenario: + 标志作用于 NaN

- **WHEN** 以 `%+f` 格式化 NaN
- **THEN** 输出 `+nan`

#### Scenario: 空格标志作用于 NaN

- **WHEN** 以 `% f` 格式化 NaN
- **THEN** 输出 ` nan`（前导空格）

#### Scenario: + 标志作用于无穷大

- **WHEN** 以 `%+f` 格式化 +∞
- **THEN** 输出 `+inf`

#### Scenario: 负无穷输出负号

- **WHEN** 以 `%f` 格式化 −∞
- **THEN** 输出 `-inf`（既有的 `num < 0` 判断保持不变）
